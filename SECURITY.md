# Security and safety reports

Please report security **and safety** problems privately, never in a public issue:

- **GitHub:** use *Security › Report a vulnerability* on this repository (private
  vulnerability reporting).
- **Otherwise:** email the maintainers at [theopenpe.team@gmail.com](mailto:theopenpe.team@gmail.com).

Include what you did, what happened, the app version (Settings › Device & developer ›
This build), your phone model and Android version, and the pump model if one was involved.
Attach the app's debug log only after removing anything personal from it.

We aim to acknowledge a report within a week. A fix for anything that could command
pressure unsafely is released before the problem is described publicly.

## Scope

In scope: anything that could make the app exceed the ceiling, fail to vent, keep running
when it should stop, expose a user's data, or send data off the phone.
