# 0001. Licence: AGPL-3.0

Date: 2026-09-22 · Status: accepted

## Context
OpenPump controls hardware, is built on reverse-engineered interoperability, and handles intimate data. Improvements made in forks should come back to users.

## Decision
License the project under the GNU Affero General Public License v3.0.

## Consequences
Forks and derived apps must stay open, including network services built on the code. Some companies will not contribute under AGPL; accepted. Precedent: Gadgetbridge (many vendors' Bluetooth devices, one open app) uses AGPL-3.0.
